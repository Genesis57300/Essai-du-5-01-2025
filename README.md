# Rombas 3D — version web

Visualisation 3D interactive de Rombas et de la vallée de l'Orne.

Cette version est 100 % statique : aucune installation et aucun serveur local ne sont nécessaires. Le navigateur charge les données réelles OpenStreetMap via Overpass ainsi que le relief SRTM 30 m, puis les conserve en cache local via IndexedDB.

Au premier affichage, une connexion Internet est nécessaire et la préparation peut prendre quelques dizaines de secondes. Les chargements suivants sont beaucoup plus rapides sur le même appareil.

Sources : OpenStreetMap / ODbL, SRTM 30 m via OpenTopoData, Three.js.
